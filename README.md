# OFFLINES / Suite — Private Workspace & Security Platform

Welcome to **OFFLINES**, an offline-first private workspace and security operating platform.

## Development Access Mode
For this development and testing phase, **all Suite modules and features are fully open and unlocked**. There are no license key requirements, subscriptions, billing, or feature locks.

### Modules Included
- **Folio**: Document Studio & Knowledge Base (.folio)
- **Grid**: Spreadsheet Data Studio (.grid)
- **Fill**: Private Form Builder & Intake Studio (.fill)
- **Spot**: Knowledge Canvas & Visual Thinking (.spot)
- **Docket**: Task Manager & Priority Matrix (.plot)
- **Almanac**: Calendar & Planner (.agnd)
- **Glides**: Presentation Studio (.glides)
- **Passwords & Lockbox**: Multi-Vault Password Manager & Encrypted File Locker (.vault, .lbox)
- **Security & Privacy Center**: Password Health Audit, k-Anonymity Breach Checking, & Observable Network Monitor

## Installation & PWA
Open `index.html` on any web server or host locally. The application registers `sw.js` and uses `manifest.json` for full PWA installation and offline caching.
