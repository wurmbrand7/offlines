Hybrid sync

Honest note: sync uploads a client-side encrypted blob to your own server (via suite-sync/), identified by a passphrase-derived Sync Key — the server can't read it. See suite-sync/README.md for setup; until that's deployed, this stays local-only.
No account. No server unless you choose sync. Every save is yours to keep — export a Capsule anytime.
A note: because nothing is stored anywhere but this device, there's no "forgot my passphrase" recovery and no cloud backup unless you make one. That's the trade — getting to "no one else can touch your data" means no one else can rescue it for you either. Export a Capsule regularly and keep it somewhere safe.
